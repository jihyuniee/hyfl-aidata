    📊 데이터를 눈에 보이게 — 시각화의 힘¶

    Part 3. 설계 — 아이디어를 서비스로 만들기 | 9차시

    🎯 이 장에서 배우는 것¶

    • 데이터 유형(비교, 추이, 비율, 관계)에 따라 적합한 차트를 선택할 수 있다
    • Python으로 데이터를 차트로 시각화하고, 인사이트를 전달하는 제목을 붙일 수 있다

    📚 핵심 개념¶

    개념 1: 차트 선택 원칙 — "질문이 차트를 결정한다"¶

    비유로 시작 ✨

    차트를 고르는 건 마치 이동 수단을 고르는 것과 같아요. 바다를 건너려면 배를, 하늘을 날려면 비행기를 타듯, 데이터에 던지는 질문의 종류에 따라 알맞은 차트가 달라집니다.

    정확한 정의

    데이터 시각화란 숫자나 텍스트로 된 데이터를 그래프, 차트, 도형 등 시각적 형태로 변환하여 패턴과 의미를 빠르게 파악하게 하는 기술입니다.

    데이터 질문 4가지와 알맞은 차트:

    • "무엇이 더 큰가?" (비교) → 📊 막대 차트
    • "시간에 따라 어떻게 변했나?" (추이) → 📈 꺾은선 차트
    • "전체에서 각각의 비중은?" (비율) → 🥧 원(파이) 차트
    • "두 값 사이에 관계가 있나?" (관계) → 🔵 산점도
    flowchart LR Q["❓ 데이터로\n무엇을 보여줄까?"] Q --> A["비교\n→ 막대 차트"] Q --> B["추이\n→ 꺾은선 차트"] Q --> C["비율\n→ 원 차트"] Q --> D["관계\n→ 산점도"]

    예시로 확인

    우리 반 학생들의 좋아하는 과목 인원수를 보여주고 싶다면? → 과목별 인원을 비교하는 것이니까 막대 차트!

    같은 데이터라도 1학기~2학기 동안 과목 선호도가 어떻게 변했는지 보여주고 싶다면? → 시간에 따른 추이이니까 꺾은선 차트!

    💡 알아보기: 원(파이) 차트는 항목이 5개 이하일 때 효과적입니다. 항목이 많아지면 조각이 너무 작아져서 오히려 읽기 어려워요.

    개념 2: 정직한 시각화 — "차트는 거짓말도 한다"¶

    비유로 시작 ✨

    같은 사진이라도 각도에 따라 완전히 다른 느낌을 주듯, 같은 데이터도 차트를 어떻게 그리느냐에 따라 전혀 다른 이야기를 전달할 수 있어요.

    왜곡이 발생하는 대표적인 경우:

    • Y축을 0부터 시작하지 않으면 → 작은 차이가 엄청나게 커 보임
    • 3D 효과를 넣으면 → 앞쪽 조각이 실제보다 크게 보임
    • 적절하지 않은 차트를 선택하면 → 메시지가 왜곡됨

    🤔 생각해보기: 매출이 100에서 105로 올랐을 때, Y축을 0부터 시작하면 거의 변화가 없어 보입니다. 하지만 Y축을 99부터 시작하면? 마치 매출이 급등한 것처럼 보이죠. 어떤 것이 정직한 시각화일까요?

    정직한 시각화 3원칙:

    1. Y축은 0부터 시작하거나, 잘랐다면 표시하기
    2. 제목에 핵심 인사이트를 담기 (예: "수학 선호도 2배 증가")
    3. 데이터 출처를 반드시 밝히기

    🔨 따라하기¶

    우리 반 학생들의 좋아하는 과목 데이터를 시각화해봅시다!

    Step 1: 데이터 준비하기¶

    # 좋아하는 과목 데이터
subjects = ['수학', '영어', '과학', '체육', '음악']
students = [8, 6, 10, 12, 4]

    실행 결과: 변수가 저장됩니다 (출력 없음).

    Step 2: 막대 차트 그리기 (비교)¶

    import matplotlib.pyplot as plt

# 한글 폰트 설정 (환경에 따라 조정)
plt.rcParams['font.family'] = 'Malgun Gothic'  # Windows
plt.rcParams['axes.unicode_minus'] = False

subjects = ['수학', '영어', '과학', '체육', '음악']
students = [8, 6, 10, 12, 4]

# 막대 차트 생성
plt.figure(figsize=(8, 5))
plt.bar(subjects, students, color=['#FF6B6B','#4ECDC4','#45B7D1','#96CEB4','#FFEAA7'])

# 인사이트를 담은 제목 붙이기
plt.title('체육이 가장 인기! — 우리 반 선호 과목', fontsize=14, fontweight='bold')
plt.xlabel('과목')
plt.ylabel('학생 수(명)')

# 막대 위에 숫자 표시
for i, v in enumerate(students):
    plt.text(i, v + 0.3, str(v), ha='center', fontweight='bold')

plt.tight_layout()
plt.savefig('bar_chart.png')
plt.show()

    실행 결과:

    체육(12명)이 가장 높은 막대, 음악(4명)이 가장 낮은 막대 차트가 출력됩니다.

    💡 알아보기: plt.text()로 막대 위에 숫자를 직접 표시하면, 독자가 Y축 눈금을 읽지 않아도 바로 값을 파악할 수 있어요.

    Step 3: 원 차트 그리기 (비율)¶

    plt.figure(figsize=(6, 6))
colors = ['#FF6B6B','#4ECDC4','#45B7D1','#96CEB4','#FFEAA7']

plt.pie(students, labels=subjects, colors=colors,
        autopct='%1.1f%%',   # 비율을 퍼센트로 표시
        startangle=90)       # 12시 방향부터 시작

plt.title('전체의 30%가 체육 선호 — 과목별 비율', fontsize=13, fontweight='bold')
plt.tight_layout()
plt.savefig('pie_chart.png')
plt.show()

    실행 결과:

    체육 30.0%, 과학 25.0%, 수학 20.0%, 영어 15.0%, 음악 10.0% 원 차트가 출력됩니다.

    Step 4: 꺾은선 차트 그리기 (추이)¶

    # 월별 독서량 추이 데이터
months = ['3월', '4월', '5월', '6월', '7월']
books = [3, 5, 4, 7, 8]

plt.figure(figsize=(8, 5))
plt.plot(months, books, marker='o', color='#45B7D1',
         linewidth=2, markersize=8)

# 각 점에 값 표시
for i, v in enumerate(books):
    plt.text(i, v + 0.3, f'{v}권', ha='center')

plt.title('꾸준히 증가! — 월별 독서량 변화', fontsize=14, fontweight='bold')
plt.xlabel('월')
plt.ylabel('독서량(권)')
plt.ylim(0, 10)  # Y축 0부터 시작 (정직한 시각화!)
plt.tight_layout()
plt.savefig('line_chart.png')
plt.show()

    실행 결과:

    3월(3권)에서 7월(8권)까지 우상향하는 꺾은선 차트가 출력됩니다.

    Step 5: 제목으로 인사이트 전달하기¶

    같은 차트라도 제목이 달라지면 메시지가 완전히 달라집니다.

    # 같은 데이터, 다른 제목 2개 비교
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# 왼쪽: 단순 나열형 제목 (별로!)
ax1.bar(subjects, students, color='#CCCCCC')
ax1.set_title('과목별 학생 수', fontsize=13)
ax1.set_ylabel('학생 수(명)')

# 오른쪽: 인사이트형 제목 (좋음!)
ax2.bar(subjects, students, color=['#FF6B6B','#4ECDC4','#45B7D1','#96CEB4','#FFEAA7'])
ax2.set_title('🏆 체육이 압도적 1위, 음악은 관심 필요', fontsize=13, fontweight='bold')
ax2.set_ylabel('학생 수(명)')

plt.tight_layout()
plt.savefig('title_comparison.png')
plt.show()

    실행 결과:

    왼쪽은 회색의 밋밋한 차트, 오른쪽은 컬러풀하고 인사이트가 담긴 차트가 나란히 출력됩니다.

    📌 정리하기: 좋은 시각화 제목은 "그래서 뭐?"라는 질문에 답합니다. "과목별 학생 수"(❌)가 아니라 "체육이 압도적 1위"(✅)처럼요!

    📝 전체 코드¶

    import matplotlib.pyplot as plt

# 한글 폰트 설정
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

# ===== 데이터 =====
subjects = ['수학', '영어', '과학', '체육', '음악']
students = [8, 6, 10, 12, 4]
colors = ['#FF6B6B','#4ECDC4','#45B7D1','#96CEB4','#FFEAA7']

# ===== 1. 막대 차트 (비교) =====
plt.figure(figsize=(8, 5))
plt.bar(subjects, students, color=colors)
plt.title('체육이 가장 인기! — 우리 반 선호 과목', fontsize=14, fontweight='bold')
plt.xlabel('과목')
plt.ylabel('학생 수(명)')
for i, v in enumerate(students):
    plt.text(i, v + 0.3, str(v), ha='center', fontweight='bold')
plt.tight_layout()
plt.show()

# ===== 2. 원 차트 (비율) =====
plt.figure(figsize=(6, 6))
plt.pie(students, labels=subjects, colors=colors, autopct='%1.1f%%', startangle=90)
plt.title('전체의 30%가 체육 선호 — 과목별 비율', fontsize=13, fontweight='bold')
plt.tight_layout()
plt.show()

# ===== 3. 꺾은선 차트 (추이) =====
months = ['3월', '4월', '5월', '6월', '7월']
books = [3, 5, 4, 7, 8]
plt.figure(figsize=(8, 5))
plt.plot(months, books, marker='o', color='#45B7D1', linewidth=2, markersize=8)
for i, v in enumerate(books):
    plt.text(i, v + 0.3, f'{v}권', ha='center')
plt.title('꾸준히 증가! — 월별 독서량 변화', fontsize=14, fontweight='bold')
plt.xlabel('월')
plt.ylabel('독서량(권)')
plt.ylim(0, 10)
plt.tight_layout()
plt.show()

    ⚠️ 주의할 점¶

    1. Y축 조작 주의: plt.ylim()으로 Y축 범위를 조절할 때, 0을 빼면 데이터가 왜곡되어 보입니다. 특별한 이유가 없다면 0부터 시작하세요.

    2. 색상은 의미를 담아서: 모든 막대를 무지개색으로 칠하면 오히려 혼란스럽습니다. 강조하고 싶은 항목만 색을 다르게 하는 것이 효과적입니다.

    ✅ 점검하기¶

    1. (기본) "2020년부터 2024년까지 우리 학교 학생 수 변화"를 보여주려면 어떤 차트가 적합할까요?

    정답 확인 **꺾은선 차트**입니다. "시간에 따른 변화(추이)"를 보여주는 질문이기 때문입니다. X축에 연도를, Y축에 학생 수를 놓으면 증가/감소 추세를 한눈에 파악할 수 있습니다.

    2. (응용) 아래 두 제목 중 더 좋은 시각화 제목은 무엇이고, 그 이유는? - (A) "월별 매출 현황" - (B) "6월 매출이 전월 대비 40% 급증"

    정답 확인 **(B)**가 더 좋습니다. (A)는 단순히 "무엇을 보여주는지"만 알려주지만, (B)는 **데이터에서 발견한 핵심 인사이트**(6월에 40% 급증)를 전달합니다. 독자가 차트를 보기 전에 핵심 메시지를 바로 이해할 수 있습니다.

    3. (심화) 같은 데이터를 막대 차트와 원 차트로 각각 그렸을 때, 전달되는 메시지는 어떻게 다를까요?

    정답 확인 - **막대 차트**: 항목 간 **절대적 크기 차이**가 강조됩니다. "체육이 음악보다 8명 더 많다"는 메시지가 잘 전달됩니다. - **원 차트**: **전체에서 차지하는 비중**이 강조됩니다. "체육이 전체의 30%를 차지한다"는 메시지가 잘 전달됩니다. 즉, **"얼마나 차이 나는지"**를 보여주려면 막대, **"전체에서 얼마나 되는지"**를 보여주려면 원 차트가 효과적입니다.
