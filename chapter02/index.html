    Chapter 2. 데이터는 흐른다 — 수집에서 AI까지¶

    🕐 예상 소요 시간: 50분

    🎯 이 장에서 배우는 것¶

    • 데이터가 수집 → 저장 → 분석 → 활용되는 4단계 흐름을 설명할 수 있다
    • 실생활 서비스에서 데이터-AI 연결 구조를 분석할 수 있다
    • 일상 속에서 데이터 기반으로 해결할 수 있는 문제를 발견할 수 있다

    📚 핵심 개념¶

    개념 1: 데이터의 생애주기 (Data Lifecycle)¶

    1. 비유로 시작

    데이터의 생애주기는 마치 요리 과정과 같아요. 장을 보고(수집) → 냉장고에 넣고(저장) → 레시피대로 조리하고(분석) → 맛있는 요리를 내놓는(활용) 것처럼, 데이터도 태어나서 쓰이기까지 단계를 거칩니다.

    2. 정확한 정의

    데이터 생애주기란, 데이터가 세상에 만들어진 순간부터 실제로 가치를 발휘할 때까지 거치는 4단계 흐름을 말합니다.

    flowchart LR A["🛒 수집\nCollection"] --> B["📦 저장\nStorage"] B --> C["🔍 분석\nAnalysis"] C --> D["🚀 활용\nApplication"] style A fill:#E3F2FD,stroke:#1565C0 style B fill:#FFF3E0,stroke:#E65100 style C fill:#E8F5E9,stroke:#2E7D32 style D fill:#FCE4EC,stroke:#C62828

    각 단계를 좀 더 살펴볼까요?

    • 🛒 수집 — 센서, 클릭, 설문, 카메라 등으로 데이터를 모으는 단계
    • 📦 저장 — 모은 데이터를 데이터베이스, 클라우드 등에 안전하게 보관하는 단계
    • 🔍 분석 — 저장된 데이터에서 패턴·규칙·의미를 찾아내는 단계
    • 🚀 활용 — 분석 결과를 서비스, 의사결정, AI 모델에 적용하는 단계

    3. 예시로 확인 — 유튜브 추천 시스템

    flowchart LR A["🛒 수집\n시청 기록, 좋아요,\n검색어, 시청 시간"] --> B["📦 저장\n구글 클라우드\n서버에 보관"] B --> C["🔍 분석\nAI가 취향 패턴 파악\n'이 사람은 게임 영상을\n오래 본다'"] C --> D["🚀 활용\n맞춤 추천 영상을\n홈 화면에 표시"]

    💡 알아보기: 유튜브는 하루에 약 10억 시간의 영상이 시청됩니다. 이 모든 시청 데이터가 4단계를 거쳐 '당신이 좋아할 영상'을 골라주는 거예요.

    개념 2: 데이터로 확인할 수 있는 문제 vs 감으로 느끼는 문제¶

    1. 비유로 시작

    "오늘 급식이 맛없었다"는 감이고, "이번 달 급식 만족도 설문 평균이 2.1/5점이었다"는 데이터입니다. 같은 불만이라도 데이터가 있으면 근거를 가지고 해결책을 찾을 수 있어요.

    2. 정확한 정의

    • 데이터 기반 문제 — 숫자, 기록, 관찰 등 객관적 증거로 확인·측정할 수 있는 문제
    • 감 기반 문제 — 느낌, 직감, 경험에만 의존하여 판단하는 문제

    3. 예시로 확인

    • "우리 반은 아침에 졸려하는 애가 많은 것 같아" → 감 기반
    • "출석부 데이터를 보니 1교시 지각률이 23%로, 다른 시간의 3배다" → 데이터 기반

    🤔 생각해보기: 여러분 주변의 불편함 중, 데이터를 모으면 정확히 확인할 수 있는 것은 무엇일까요?

    생각 확장: 도메인 지식이 문제의 깊이를 만든다

    AI 도구는 사용법만 안다고 바로 좋은 결과를 내지 않습니다. 사용자가 어떤 분야의 문제를 이해하고 있고, 무엇을 해결하려는지 분명할 때 도구가 제 역할을 합니다. 이때 필요한 배경 이해를 도메인 지식이라고 부릅니다.

    가벼운 주제도 질문을 바꾸면 깊어질 수 있습니다. 아래처럼 한 단계 더 들어가 보세요.

    처음 떠올린 주제 가벼운 질문 도메인 지식을 더한 질문
    급식 인기 메뉴는 무엇일까? 시험 기간, 계절, 영양 기준에 따라 급식 구성이 어떻게 달라질까?
    날씨 올해는 더웠을까? 기온 변화가 학교 냉방, 건강, 등하교 생활과 어떤 관련이 있을까?
    영화 어떤 영화가 1등일까? 개봉 시기, 장르, 상영관 수가 관객 수에 어떤 영향을 줄까?
    교육 학교별 차이가 있을까? 지역, 교육과정, 진학 특성, 학생 수 변화를 함께 보면 어떤 패턴이 보일까?

    좋은 데이터 프로젝트는 데이터 찾기에서 끝나지 않고, 문제의 배경 이해 → 질문 만들기 → 데이터로 확인하기 → 도구로 표현하기까지 이어집니다.

    🔨 따라하기: ChatGPT로 서비스의 데이터 흐름 분석하기¶

    이번 실습에서는 ChatGPT에 프롬프트(질문)를 입력하여 실생활 서비스의 데이터 흐름을 분석해 봅니다.

    Step 1: ChatGPT 접속하기¶

    ChatGPT(chat.openai.com)에 접속하여 대화창을 엽니다. 계정이 없다면 무료 가입 후 진행하세요.

    Step 2: 데이터 흐름 분석 프롬프트 입력하기¶

    코드 (ChatGPT 대화창에 입력): 

    카카오맵 길찾기 서비스가 사용하는 데이터를 
"수집 → 저장 → 분석 → 활용" 4단계로 나누어 
중학생도 이해할 수 있게 설명해 줘.

    예상 출력 (ChatGPT 답변 요약): 

    수집: GPS 위치, 실시간 교통량, 버스/지하철 도착 정보, 사용자 검색 기록
저장: 카카오 클라우드 서버에 지도 데이터와 함께 보관
분석: AI가 현재 교통 상황을 반영해 가장 빠른 경로를 계산
활용: 사용자에게 최적 경로, 예상 소요 시간, 대안 경로를 표시

    Step 3: 다른 서비스로 바꿔보기¶

    프롬프트에서 "카카오맵 길찾기"를 아래 중 하나로 바꿔 입력해 보세요.

    • 멜론 음악 추천
    • 배달의민족 맛집 추천
    • 넷플릭스 콘텐츠 추천
    넷플릭스 콘텐츠 추천 서비스가 사용하는 데이터를 
"수집 → 저장 → 분석 → 활용" 4단계로 나누어 
중학생도 이해할 수 있게 설명해 줘.

    Step 4: 결과를 데이터 흐름도로 정리하기¶

    ChatGPT 답변을 참고하여, 아래 Python 코드를 실행해 보세요. 원하는 서비스의 내용으로 텍스트를 수정하면 나만의 흐름도가 됩니다.

    코드: 

    # 데이터 흐름 4단계 정리 프로그램
service = "카카오맵 길찾기"

stages = {
    "1단계 수집": "GPS 위치, 실시간 교통량, 검색 기록",
    "2단계 저장": "카카오 클라우드 서버에 보관",
    "3단계 분석": "AI가 최적 경로 계산",
    "4단계 활용": "사용자에게 최적 경로 안내"
}

print(f"📊 [{service}] 데이터 흐름도")
print("=" * 40)

for stage, description in stages.items():
    print(f"  ➡️  {stage}")
    print(f"      {description}")
    print()

print("🎯 데이터가 이 흐름을 따라 AI까지 연결됩니다!")

    Step 5: 우리 학교 데이터 찾기¶

    이번에는 시선을 우리 학교로 돌려봅시다. 아래 코드를 실행하고, 빈칸을 직접 채워 보세요.

    코드:

    "출석 기록",
    "급식 잔반량",
    "도서관 대출 기록",

    # "___",
    # "___",

print("=" * 35)
for i, data in enumerate(school_data, 1):
    print(f"  {i}. {data}")

print(f"\n총 {len(school_data)}개 발견! 목표: 5개 이상 🎯")

    ⚠️ 주의할 점¶

    1. 데이터 흐름은 한 방향이 아닐 수 있어요 실제 서비스에서는 활용 결과가 다시 수집 단계로 돌아가는 순환 구조가 많습니다. 예를 들어, 유튜브에서 추천 영상을 클릭하면 그 클릭 자체가 새로운 데이터로 수집됩니다.

    flowchart LR A["수집"] --> B["저장"] --> C["분석"] --> D["활용"] D -- "새로운 데이터 발생" --> A

    2. 모든 문제를 데이터로 해결할 수 있는 것은 아니에요 "점심시간이 왜 이렇게 짧게 느껴질까?"는 감정의 영역이지만, "점심시간 동안 학생들이 실제로 식사에 쓰는 시간"은 데이터로 측정할 수 있습니다. 문제를 어떻게 표현하느냐에 따라 데이터 활용 가능성이 달라집니다.

    정답 확인 수집(Collection) → 저장(Storage) → 분석(Analysis) → 활용(Application)

    응용 문제 2. 배달의민족에서 "이 식당 어때요?"라고 추천해 줄 때, 어떤 데이터가 수집 단계에서 모일까요? 3가지 이상 쓰세요.

    정답 확인 - 사용자의 주문 내역 (어떤 음식을 자주 시켰는지) - 식당 평점과 리뷰 데이터 - 사용자의 현재 위치 (GPS) - 주문 시간대 (점심/저녁 패턴) - 검색 기록 (어떤 메뉴를 검색했는지)

    심화 문제 3. "우리 학교 화장실이 쉬는 시간마다 너무 붐빈다"는 문제를 데이터 기반 문제로 바꿔 표현하고, 4단계 흐름을 설계해 보세요.

    정답 확인 **데이터 기반 표현**: "쉬는 시간 10분 동안 각 층 화장실 이용 인원수를 측정해, 가장 혼잡한 층과 시간대를 파악한다" - **수집**: 각 층 화장실 앞에 인원 카운터 설치, 시간대별 이용자 수 기록 - **저장**: 스프레드시트 또는 간단한 데이터베이스에 일별로 저장 - **분석**: 층별·시간대별 평균 이용자 수를 비교하여 혼잡 패턴 파악 - **활용**: 가장 붐비는 시간에 다른 층 화장실 이용을 안내하는 알림 시스템 제안
