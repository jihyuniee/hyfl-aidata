    Chapter 1. 공공데이터, 이미 우리 곁에 있다¶

    Part 1. 출발 — 데이터로 세상 보기 | 1차시 (50분)

    🎯 이 장에서 배우는 것¶

    • 공공데이터의 정의와 종류를 설명할 수 있다
    • 교육 공공데이터 포털에 접속하여 데이터를 검색할 수 있다
    • 제8회 교육 공공데이터 AI 활용대회의 참가 조건과 일정을 파악할 수 있다

    📚 핵심 개념¶

    개념 1: 공공데이터¶

    1. 비유로 시작

    🏫 학교 도서관의 책은 누구나 빌려볼 수 있죠? 공공데이터는 마치 국가가 운영하는 거대한 도서관과 같아요. 다만 책 대신 숫자, 텍스트, 통계 같은 데이터가 꽂혀 있고, 인터넷만 있으면 누구든 무료로 꺼내 쓸 수 있습니다.

    2. 정확한 정의

    공공데이터란 공공기관(정부, 지자체, 학교 등)이 업무 중에 만들거나 수집한 데이터로, 국민 누구나 자유롭게 이용할 수 있도록 개방한 정보를 말합니다. 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 근거합니다.

    3. 예시로 확인 — 이미 우리 곁에 있는 공공데이터

    • 🍱 오늘의 급식 메뉴 → 나이스(NEIS) 교육정보에서 매일 공개
    • 🏫 전국 학교 정보(주소, 학생 수, 교원 수) → 학교알리미에서 공개
    • 🚌 버스 도착 예정 시간 → 지자체 교통 공공데이터에서 제공
    • 🌤️ 내일 날씨 예보 → 기상청 공공데이터에서 제공

    💡 알아보기: 우리가 스마트폰에서 매일 쓰는 날씨 앱, 지도 앱, 급식 앱 대부분이 공공데이터 API(프로그램이 데이터를 자동으로 가져오는 통로)를 활용하고 있어요!

    개념 2: 교육 공공데이터 포털¶

    1. 비유로 시작

    🛒 마트에 가면 과일, 채소, 생선이 코너별로 정리되어 있죠? 교육 공공데이터 포털은 교육 분야 데이터만 모아놓은 전문 마트와 같아요. 학교 정보, 진학 통계, 학업성취도 등 교육 데이터를 한 곳에서 검색하고 내려받을 수 있습니다.

    2. 주요 포털 3곳

    • 📌 공공데이터포털 (data.go.kr) — 전 분야 공공데이터 총집합
    • 📌 학교알리미 (schoolinfo.go.kr) — 전국 초·중·고 학교별 공시 정보
    • 📌 교육통계서비스 (kess.kedi.re.kr) — 교육부 공식 통계·연보

    3. 공공데이터의 핵심 특징 3가지

    graph LR A["🔓 개방성<br/>누구나 접근 가능"] --> D["공공데이터"] B["💰 무료<br/>별도 비용 없음"] --> D C["♻️ 재사용 가능<br/>분석·앱 개발 등<br/>자유롭게 활용"] --> D

    🤔 생각해보기: 평소 학교에 대해 궁금했던 것이 있나요? "우리 학교 학생 수가 작년보다 줄었을까?", "급식비는 전국 평균과 비교하면 어떨까?" 같은 질문을 떠올려 보세요. 이 질문들의 답이 바로 공공데이터 안에 있습니다!

    🔨 따라하기: 학교알리미에서 우리 학교 데이터 찾기¶

    Step 1: 학교알리미 접속¶

    웹 브라우저를 열고 주소창에 입력합니다.

    https://www.schoolinfo.go.kr

    첫 화면 상단의 검색창이 보이면 준비 완료!

    Step 2: 우리 학교 검색¶

    검색창에 자신의 학교 이름을 입력하고 🔍 버튼을 클릭합니다.

    예시: 서울중학교 입력 → 검색 결과에서 정확한 학교를 선택

    Step 3: 공시 항목 탐색¶

    학교 페이지에 들어가면 다양한 공시 항목이 카테고리로 나뉘어 있습니다.

    graph TD S["🏫 학교알리미<br/>우리 학교 페이지"] S --> A["학생 현황"] S --> B["교원 현황"] S --> C["급식 현황"] S --> D["학업성취도"] S --> E["예·결산 현황"]

    각 항목을 클릭하면 연도별 데이터를 확인할 수 있습니다.

    Step 4: 데이터 항목 5개 이상 찾아보기¶

    아래 예시처럼, 자신이 찾은 항목을 메모장이나 노트에 정리해 보세요.

    • 항목 1: 학생 수 (남/여, 학년별)
    • 항목 2: 교원 1인당 학생 수
    • 항목 3: 급식 식단 및 1식당 급식비
    • 항목 4: 방과후학교 운영 현황
    • 항목 5: 졸업생 진로 현황

    📸 화면을 스크린샷으로 저장해 두면 나중에 팀 활동에서 공유할 때 편리합니다!

    Step 5: 공공데이터포털에서 파일 다운로드 체험¶

    https://www.data.go.kr
    1. 접속 후 검색창에 학교 기본정보를 입력합니다.
    2. 검색 결과에서 "전국 학교 기본정보" 데이터셋을 클릭합니다.
    3. 파일 데이터 탭에서 CSV 또는 XLSX 형식의 다운로드 버튼을 누릅니다.
    4. 내려받은 파일을 엑셀이나 구글 스프레드시트로 열어봅니다.

    ✅ 수천 개 학교의 정보가 한 파일에 담겨 있는 것을 확인할 수 있어요. 이것이 공공데이터의 힘입니다!

    📝 전체 코드: Python으로 공공데이터 미리 맛보기¶

    아래 코드는 다운로드한 CSV 파일을 파이썬으로 열어보는 가장 기초적인 예제입니다. 지금 당장 실행하지 않아도 괜찮아요. "아, 이런 식으로 데이터를 다루는구나"를 느끼는 것이 목표입니다.

    # school_data_preview.py
# 공공데이터포털에서 내려받은 학교 기본정보 CSV를 열어봅니다

import pandas as pd  # 데이터 분석 라이브러리

# 1. 파일 읽기 (파일 이름은 실제 다운로드한 파일에 맞게 수정)
df = pd.read_csv("school_info.csv", encoding="cp949")

# 2. 처음 5줄 미리보기
print("=== 데이터 미리보기 ===")
print(df.head())

# 3. 전체 행(학교) 수 확인
print(f"\n전체 학교 수: {len(df)}개")

# 4. 어떤 열(항목)이 있는지 확인
print(f"\n데이터 항목: {list(df.columns)}")

1  나다중학교    중학교   부산   사립     ...
...

    🏆 대회 소개: 제8회 교육 공공데이터 AI 활용대회¶

    이 교재는 교육 공공데이터 AI 활용대회 참가를 목표로 합니다. 핵심 정보를 정리하면 다음과 같습니다.

    • 📋 대회 목적 — 교육 공공데이터와 AI를 활용하여 교육 문제를 해결하는 아이디어 및 결과물 경진
    • 👥 참가 대상 — 학생 팀 (구성 방법은 대회 공고 확인)
    • 📅 일정 — 매년 상반기 공고 → 하반기 본선 (정확한 날짜는 공식 홈페이지에서 반드시 확인!)
    • 🎁 혜택 — 수상 실적, AI이용권(클라우드 크레딧) 제공 등
    • 🌐 공식 안내 — 교육부·한국교육학술정보원(KERIS) 홈페이지

    💡 알아보기: AI이용권이란 클라우드 컴퓨팅 자원을 무료로 사용할 수 있는 쿠폰 같은 것입니다. 대회 참가 팀에게 제공되어, 고성능 컴퓨터가 없어도 AI 모델을 학습시킬 수 있어요!

    ⚠️ 주의할 점¶

    1. 개인정보가 포함된 데이터는 공공데이터가 아닙니다. 공공데이터는 개인을 식별할 수 없도록 처리(비식별화)된 상태로 공개됩니다. 학생 개인의 성적, 이름 등은 절대 포함되지 않아요.

    2. CSV 파일의 인코딩 오류에 주의하세요. 한글이 깨져 보인다면 encoding="cp949" 또는 encoding="utf-8"을 바꿔가며 시도해 보세요.

    ✅ 점검하기¶

    기본 문제

    1. 공공데이터의 핵심 특징 3가지를 말해 보세요.
    정답 확인 **개방성**(누구나 접근 가능), **무료**(비용 없음), **재사용 가능**(분석·앱 개발 등 자유 활용)
    1. 전국 학교의 급식 정보나 학생 수를 확인할 수 있는 포털 이름은 무엇인가요?
    정답 확인 **학교알리미** (schoolinfo.go.kr). 공공데이터포털(data.go.kr)에서도 파일로 내려받을 수 있습니다.

    응용 문제

    1. 스마트폰의 "날씨 앱"과 "버스 도착 앱"은 공공데이터를 어떻게 활용하고 있을까요? 자신의 말로 설명해 보세요.
    정답 확인 날씨 앱은 **기상청 공공데이터 API**를 통해 실시간 날씨·예보 데이터를 받아와 화면에 보여줍니다. 버스 앱은 **지자체 교통 공공데이터 API**에서 버스 위치·도착 예정 시간 데이터를 받아옵니다. 즉, 앱 개발자가 직접 날씨를 관측하거나 버스를 추적하는 것이 아니라, 공공기관이 이미 수집·공개한 데이터를 **재사용**하는 것입니다.

    🚀 도전 문제

    1. 학교알리미에 접속하여 자신의 학교 데이터 항목 5개 이상을 찾고, 스크린샷과 함께 학습 노트에 정리해 보세요. 각 항목이 어떤 질문에 답할 수 있는지도 함께 적어 봅시다.

    예: "교원 현황" → "우리 학교 선생님은 몇 분일까?"에 답할 수 있다.
