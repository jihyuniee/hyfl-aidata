    📖 Chapter 4. 교육 공공데이터, 어디에 뭐가 있을까¶

    Part 2. 탐색 — 데이터를 찾고 읽고 연결하기 | ⏱️ 50분

    🎯 이 장에서 배우는 것¶

    • 4대 교육 데이터 플랫폼(학교알리미, 교육통계서비스, 공공데이터포털, NEIS)의 특성과 제공 데이터를 구분할 수 있다
    • 우리 팀 문제에 적합한 데이터셋을 찾아 다운로드하고, 데이터 프로필 카드를 작성할 수 있다

    📚 핵심 개념¶

    개념 1: 교육 데이터 플랫폼 — "같은 학교, 다른 정보"¶

    💡 비유로 시작: 같은 사람을 소개할 때, 병원에서는 건강 기록을, 학교에서는 성적표를, 은행에서는 신용 정보를 내놓죠? 교육 데이터 플랫폼도 마찬가지입니다. '학교'라는 같은 키워드로 검색해도, 어느 사이트에서 찾느냐에 따라 완전히 다른 데이터가 나옵니다.

    정확한 정의: 교육 데이터 플랫폼이란, 정부 및 공공기관이 교육 관련 정보를 수집·가공하여 시민에게 공개하는 웹사이트입니다.

    4대 플랫폼을 한눈에 살펴봅시다 👇

    📌 알아보기: 플랫폼마다 "강점 영역"이 다릅니다. - 학교알리미 → "00고등학교의 올해 졸업생 진학률은?" 처럼 특정 학교를 깊이 파고들 때 - 교육통계서비스 → "전국 학급당 학생 수가 10년간 어떻게 변했지?" 처럼 전국·시도 단위 추세를 볼 때 - 공공데이터포털 → "학교 주변 미세먼지 데이터도 함께 구하고 싶어!" 처럼 교육 + 다른 분야를 결합할 때 - NEIS Open API → "이번 주 우리 학교 급식 식단은?" 처럼 실시간·최신 정보가 필요할 때

    개념 2: 데이터 프로필 카드 — "데이터의 신분증"¶

    💡 비유로 시작: 여러분이 처음 만난 사람과 대화하려면 이름, 나이, 관심사 정도는 알아야 하죠? 데이터도 마찬가지입니다. 다운로드한 파일을 열기 전에 "이 데이터가 누구인지" 정리하는 것이 데이터 프로필 카드입니다.

    정확한 정의: 데이터 프로필 카드란, 데이터셋의 출처, 수집 기간, 행 수, 주요 컬럼(항목), 파일 형식을 한 장에 정리한 요약 문서입니다.

    예시 — 학교알리미에서 다운로드한 파일의 프로필 카드

    • 데이터셋 이름: 2024년 서울특별시 고등학교 졸업생 진로 현황
    • 출처(URL): schoolinfo.go.kr → 공시정보 → 졸업생 진로현황
    • 수집 기간: 2024년 (연 1회 공시)
    • 행 수: 약 320행 (서울 소재 고등학교 수)
    • 주요 컬럼: 학교명, 학교코드, 졸업생수, 대학진학자수, 취업자수, 기타
    • 파일 형식: CSV (UTF-8)
    • 공통 키 후보: 학교코드 (다른 데이터와 연결 가능!)

    🤔 생각해보기: 왜 프로필 카드가 중요할까요? 나중에 3~4개 데이터를 합칠 때, "이 데이터의 기간이 맞나?", "공통으로 쓸 수 있는 컬럼이 있나?"를 빠르게 판단할 수 있기 때문입니다.

    🔨 따라하기¶

    실습 목표: 학교알리미에서 데이터를 다운로드하고, Python으로 데이터 프로필 카드를 자동 생성해 봅시다.

    Step 1: 학교알리미에서 데이터 다운로드¶

    1. 웹 브라우저에서 schoolinfo.go.kr 접속
    2. 상단 메뉴 [공시정보] → [학교현황] 선택
    3. 지역을 서울특별시로 설정, 학교급을 고등학교로 선택
    4. [엑셀 다운로드] 클릭 → 파일명을 school_status_seoul.csv로 저장

    ⚠️ 엑셀(.xls)로 다운로드된 경우, 엑셀에서 열고 [다른 이름으로 저장] → CSV(UTF-8) 로 저장하세요.

    Step 3: 데이터 프로필 카드 자동 생성¶

    # 데이터 프로필 카드 출력 함수
def print_profile_card(df, name, source, period):
    print("=" * 50)
    print(f"📇 데이터 프로필 카드")
    print(f"  이름: {name}")
    print(f"  출처: {source}")
    print(f"  기간: {period}")
    print(f"  행 수: {df.shape[0]}행")
    print(f"  열 수: {df.shape[1]}개")
    print(f"  주요 컬럼: {list(df.columns[:5])} ...")
    print(f"  결측치 현황:")
    for col in df.columns:
        null_count = df[col].isnull().sum()
        if null_count > 0:
            print(f"    ⚠️ {col}: {null_count}개 비어있음")
    if df.isnull().sum().sum() == 0:
        print(f"    ✅ 결측치 없음!")
    print("=" * 50)

# 실행
print_profile_card(
    df,
    name="서울 고등학교 학교현황",
    source="학교알리미 (schoolinfo.go.kr)",
    period="2024년"
)

    Step 4: 두 번째 데이터셋도 찾아보기¶

    같은 방법으로 공공데이터포털(data.go.kr)에서 관련 데이터를 하나 더 찾아봅시다.

    1. data.go.kr 접속 → 검색창에 "학교 현황" 입력
    2. 필터에서 [파일데이터] 선택 → CSV 파일 다운로드
    3. 같은 코드로 프로필 카드 생성
    # 두 번째 데이터도 같은 방식으로 확인
df2 = pd.read_csv("second_dataset.csv", encoding="utf-8")

print_profile_card(
    df2,
    name="전국 학교 기본정보",

    Step 5: 공통 키(연결 고리) 찾기¶

    # 두 데이터에 공통 컬럼이 있는지 확인
common_cols = set(df.columns) & set(df2.columns)
print("🔗 공통 컬럼:", common_cols)
# 예상 출력: {'학교코드', '학교명'}

    📌 정리하기: 학교코드가 양쪽 데이터 모두에 있다면, 나중에 이 코드를 기준으로 두 데이터를 합칠 수 있습니다. 이것이 바로 공통 키입니다!

    📝 전체 코드¶

    import pandas as pd

# --- 프로필 카드 함수 ---
def print_profile_card(df, name, source, period):
    print("=" * 50)
    print(f"📇 데이터 프로필 카드")
    print(f"  이름: {name}")
    print(f"  출처: {source}")
    print(f"  기간: {period}")
    print(f"  행 수: {df.shape[0]}행")
    print(f"  열 수: {df.shape[1]}개")
    print(f"  주요 컬럼: {list(df.columns[:5])} ...")
    print(f"  결측치 현황:")
    for col in df.columns:
        null_count = df[col].isnull().sum()
        if null_count > 0:
            print(f"    ⚠️ {col}: {null_count}개 비어있음")
    if df.isnull().sum().sum() == 0:
        print(f"    ✅ 결측치 없음!")
    print("=" * 50)

# --- 데이터 1: 학교알리미 ---
df1 = pd.read_csv("school_status_seoul.csv", encoding="utf-8")
print_profile_card(df1, "서울 고등학교 학교현황", "학교알리미", "2024년")

# --- 데이터 2: 공공데이터포털 ---
df2 = pd.read_csv("second_dataset.csv", encoding="utf-8")
print_profile_card(df2, "전국 학교 기본정보", "공공데이터포털", "2024년")

# --- 공통 키 확인 ---
common_cols = set(df1.columns) & set(df2.columns)
print(f"\n🔗 공통 컬럼: {common_cols}")

    ⚠️ 주의할 점¶

    1. 인코딩 문제: 공공데이터 CSV 파일은 euc-kr로 저장된 경우가 많습니다. utf-8로 열리지 않으면 encoding="euc-kr"로 바꿔 보세요.
    2. 같은 이름, 다른 의미: 두 플랫폼의 "학생수" 컬럼이 같은 기준 시점인지 반드시 확인하세요. 3월 기준과 9월 기준은 수치가 다릅니다!

    ✅ 점검하기¶

    [기본] 1. "우리 학교의 올해 급식 식단"을 알고 싶다면 어떤 플랫폼이 가장 적합할까요?

    정답 확인 NEIS Open API입니다. 실시간 급식 식단 정보를 API로 제공하며, 학교알리미는 연 단위 통계만 제공합니다.

    [응용] 2. "서울시 고등학교 학생 수 변화(10년)"를 분석하려면 어떤 플랫폼에서 시작하는 것이 좋을까요?

    정답 확인 교육통계서비스(kess.kedi.re.kr)입니다. 시도 단위로 연도별 추이 통계를 제공하므로, 10년치 데이터를 한번에 조회할 수 있습니다.

    [심화] 3. 학교알리미의 "학교코드"와 NEIS의 "학교코드"가 동일한 체계를 사용한다면, 이 두 데이터를 합칠 때 어떤 이점이 있을까요?

    정답 확인 학교코드를 공통 키로 사용하여 학교알리미의 학생수·진학률 데이터와 NEIS의 시간표·급식 데이터를 하나로 연결할 수 있습니다. 예를 들어 "급식 만족도가 높은 학교의 학생 수 변화"같은 복합 분석이 가능해집니다.

    📌 핵심 개념 요약 - 4대 교육 데이터 플랫폼은 각각 개별 학교(학교알리미), 전국 통계(교육통계서비스), 다분야 융합(공공데이터포털), 실시간 학사정보(NEIS API)에 강점이 있다 - 데이터를 다운로드하면 반드시 프로필 카드(출처, 기간, 행 수, 주요 컬럼, 공통 키)를 작성하여 데이터의 정체를 파악한다
