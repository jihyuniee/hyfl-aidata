    데이터가 말해주는 이야기¶

    Part 2. 탐색 — 데이터를 찾고 읽고 연결하기 | 5차시

    🎯 이 장에서 배우는 것¶

    • 구글 스프레드시트에서 정렬, 필터, 피벗 테이블을 사용하여 데이터를 탐색할 수 있다
    • 데이터에서 의미 있는 인사이트(패턴, 이상값, 트렌드)를 발견하고 문장으로 표현할 수 있다
    • ChatGPT에 데이터 분석을 요청하는 프롬프트를 작성하여 내 분석과 비교할 수 있다

    📚 핵심 개념¶

    개념 1: 데이터 탐색 — 질문을 던져야 이야기가 시작된다¶

    1. 비유로 시작: 데이터 탐색은 마치 탐정이 사건 현장을 조사하는 것과 같아요. 단서(숫자)는 여기저기 흩어져 있지만, "누가? 언제? 왜?"라는 질문을 던져야 비로소 사건의 윤곽이 드러납니다.

    2. 정확한 정의: 데이터 탐색(Exploratory Data Analysis)이란, 수집한 데이터에 질문을 던지고 정렬·필터·요약 등의 도구로 답을 찾아가는 과정입니다. 분석의 첫 단추이자 가장 중요한 단계입니다.

    3. 예시로 확인: "전국 시도별 1인당 쓰레기 배출량" 데이터가 있다고 합시다. 그냥 보면 숫자 나열이지만, "가장 많이 배출하는 지역은?"이라고 질문하는 순간, 정렬 한 번으로 답이 보입니다.

    💡 알아보기: 좋은 탐색 질문의 3가지 유형 - 순위 질문 — "가장 높은/낮은 값은 무엇인가?" - 비교 질문 — "그룹(지역, 연도, 성별 등)별 차이가 있는가?" - 변화 질문 — "시간에 따라 증가/감소하는 추세가 있는가?"

    개념 2: 인사이트 — 데이터가 들려주는 '의미 있는 발견'¶

    1. 비유로 시작: 인사이트는 마치 퍼즐 조각을 맞춰서 완성된 그림의 한 장면을 보는 것과 같아요. 숫자 하나하나는 조각이지만, 연결하면 이야기가 됩니다.

    2. 정확한 정의: 인사이트(Insight)란, 데이터에서 발견한 패턴(pattern), 이상값(outlier), 트렌드(trend) 등을 해석하여 "그래서 이것이 무엇을 의미하는가"를 문장으로 표현한 것입니다.

    3. 예시로 확인:

    4. 패턴: "인구가 많은 도시일수록 1인당 배출량은 오히려 낮은 경향이 있다"
    5. 이상값: "제주도만 유독 1인당 배출량이 전국 평균의 2배다"
    6. 트렌드: "2018년부터 2023년까지 재활용률이 매년 약 2%p씩 상승했다"

    🔨 따라하기¶

    📋 준비물: 4차시에서 다운로드한 CSV 파일 (또는 아래 예시 데이터), 구글 스프레드시트, ChatGPT

    이번 실습에서는 "시도별 연간 1인당 생활폐기물 배출량" 데이터를 사용합니다. 4차시에서 받은 데이터가 없다면, 구글 스프레드시트에 아래 데이터를 직접 입력하세요.

    예시 데이터 (8개 시도 × 3개 연도) - 열(컬럼): 시도명, 연도, 1인당배출량(kg), 재활용률(%) - 서울 / 2021 / 0.92 / 62.1 - 서울 / 2022 / 0.89 / 63.5 - 서울 / 2023 / 0.87 / 65.0 - 부산 / 2021 / 1.05 / 58.3 - 부산 / 2022 / 1.02 / 59.1 - 부산 / 2023 / 0.98 / 60.8 - 대구 / 2021 / 1.10 / 55.7 - 대구 / 2022 / 1.08 / 56.9 - 대구 / 2023 / 1.04 / 58.2 - 인천 / 2021 / 1.15 / 54.0 - 인천 / 2022 / 1.12 / 55.3 - 인천 / 2023 / 1.09 / 57.1 - 광주 / 2021 / 0.98 / 60.2 - 광주 / 2022 / 0.95 / 61.0 - 광주 / 2023 / 0.93 / 62.5 - 제주 / 2021 / 1.85 / 45.2 - 제주 / 2022 / 1.90 / 44.8 - 제주 / 2023 / 1.88 / 46.0 - 세종 / 2021 / 1.20 / 52.0 - 세종 / 2022 / 1.25 / 51.5 - 세종 / 2023 / 1.22 / 53.0 - 경기 / 2021 / 1.00 / 59.5 - 경기 / 2022 / 0.97 / 60.8 - 경기 / 2023 / 0.95 / 62.0

    Step 1: 데이터를 구글 스프레드시트에 올리기¶

    1. Google Sheets에 접속하여 새 스프레드시트를 만듭니다.
    2. 4차시 CSV 파일이 있다면: 파일 → 가져오기 → 업로드 탭에서 파일을 올립니다.
    3. 없다면: 위 예시 데이터를 A1셀부터 직접 입력합니다. (A열: 시도명, B열: 연도, C열: 1인당배출량, D열: 재활용률)

    🔍 생각해보기: 데이터를 올린 후, 행(row)은 몇 개이고 열(column)은 몇 개인지 확인해보세요. 이것만으로도 "이 데이터의 규모"라는 첫 번째 정보를 얻은 것입니다.

    Step 2: 정렬로 순위 질문에 답하기¶

    "1인당 배출량이 가장 높은 지역은 어디일까?"

    1. C열(1인당배출량) 헤더를 클릭합니다.
    2. 메뉴에서 데이터 → 시트 정렬 → Z→A(내림차순)를 선택합니다.
    3. 맨 위에 올라온 행을 확인합니다.

    실행 결과 (예상):

    제주 / 2022 / 1.90 / 44.8 이 가장 위에 옵니다.

    ✏️ 여러분의 발견을 메모장이나 시트 옆에 적어보세요:

    📌 인사이트 #1: "제주도의 1인당 생활폐기물 배출량(1.90kg)은 서울(0.87kg)의 약 2.2배로, 전국에서 가장 높다."

    Step 3: 필터로 비교 질문에 답하기¶

    "2023년 데이터만 골라서 지역 간 차이를 보고 싶다면?"

    1. 첫 번째 행(헤더)을 선택한 후, 데이터 → 필터 만들기를 클릭합니다.
    2. B열(연도) 헤더에 생긴 ▼ 아이콘을 클릭합니다.
    3. "모두 선택 해제" 후, 2023만 체크하고 확인을 누릅니다.
    4. 이제 2023년 데이터만 화면에 표시됩니다.

    실행 결과 (예상):

    2023년 기준 — 서울 0.87 / 부산 0.98 / 대구 1.04 / 인천 1.09 / 광주 0.93 / 제주 1.88 / 세종 1.22 / 경기 0.95

    📌 인사이트 #2: "2023년 기준, 서울(0.87kg)이 가장 적고 제주(1.88kg)가 가장 많아 약 2.16배 차이가 난다."

    Step 4: 피벗 테이블로 트렌드 질문에 답하기¶

    "연도별로 전체 평균 배출량이 줄고 있을까?"

    1. 필터를 해제합니다 (데이터 → 필터 해제).
    2. 전체 데이터 범위를 선택한 후, 삽입 → 피벗 테이블을 클릭합니다.
    3. "새 시트"를 선택하고 만들기를 누릅니다.
    4. 피벗 테이블 편집기에서 설정합니다:
    5. 행: 연도
    6. 값: 1인당배출량 → 요약 기준: AVERAGE(평균)
    7. 결과를 확인합니다.

    실행 결과 (예상):

    • 2021년 평균: 1.16kg
    • 2022년 평균: 1.15kg
    • 2023년 평균: 1.12kg

    📌 인사이트 #3: "2021~2023년 전국 평균 1인당 배출량이 1.16→1.12kg으로 매년 감소 추세를 보인다."

    💡 알아보기: 피벗 테이블이란? 피벗(Pivot)은 "축을 중심으로 돌린다"는 뜻입니다. 원본 데이터를 원하는 기준(행)과 계산 방식(값)으로 재배치해서 요약해주는 강력한 도구입니다. 수백, 수천 행의 데이터도 한 번에 요약할 수 있어요.

    Step 5: ChatGPT에게 데이터 분석 요청하기¶

    이제 여러분이 직접 발견한 인사이트를 ChatGPT의 분석과 비교해봅니다.

    ChatGPT에 보낼 프롬프트:

    아래는 시도별 연간 1인당 생활폐기물 배출량(kg)과 재활용률(%) 데이터야.

서울, 2021, 0.92, 62.1
서울, 2022, 0.89, 63.5
서울, 2023, 0.87, 65.0
부산, 2021, 1.05, 58.3
부산, 2022, 1.02, 59.1
부산, 2023, 0.98, 60.8
(... 나머지 데이터도 모두 붙여넣기 ...)

이 데이터에서 흥미로운 패턴, 이상값, 트렌드를 3가지 이상 찾아서
각각 한 문장으로 설명해줘.

    ChatGPT 응답 예시:

    1. 제주도는 1인당 배출량이 다른 시도 대비 약 1.5~2배 높은 이상값입니다.
    2. 모든 시도에서 2021→2023년 배출량이 감소하는 공통 트렌드가 관찰됩니다. (단, 세종은 2022년에 일시 증가)
    3. 배출량이 낮을수록 재활용률이 높은 역의 상관관계가 보입니다.

    🔍 생각해보기: ChatGPT의 분석과 여러분의 분석을 비교해보세요. - 같은 점은 무엇인가요? - ChatGPT가 발견했지만 내가 놓친 것은? - 반대로, ChatGPT가 틀렸거나 과장한 부분은 없나요?

    이렇게 자신의 탐색 결과와 AI의 분석을 교차 확인하는 습관은 데이터 리터러시의 핵심입니다. AI를 맹신하지도, 무시하지도 않는 것이죠.

    ⚠️ 주의할 점¶

    1. 인사이트 ≠ 숫자 읽기: "서울은 0.87이다"는 인사이트가 아닙니다. "서울은 전국에서 가장 낮으며, 이는 높은 재활용률과 관련이 있을 수 있다"처럼 비교·해석·맥락이 담겨야 인사이트입니다.

    2. 상관관계 ≠ 인과관계: "배출량이 낮은 지역이 재활용률이 높다"는 상관관계이지, "재활용을 많이 해서 배출량이 줄었다"는 인과관계는 이 데이터만으로 증명할 수 없습니다. ChatGPT도 종종 상관을 인과로 표현하니 주의하세요.

    ✅ 점검하기¶

    기본 문제¶

    1. 다음 중 "인사이트"에 해당하는 문장은 무엇일까요? - (가) "서울의 2023년 배출량은 0.87kg이다." - (나) "제주는 유일하게 배출량이 1.5kg을 넘으며, 관광객 유입이 원인일 수 있다."

    정답 확인 **(나)**가 인사이트입니다. (가)는 단순한 데이터 읽기이고, (나)는 비교("유일하게 1.5kg 초과")와 맥락("관광객 유입")이 포함된 해석입니다.

    2. 피벗 테이블에서 "행: 시도명, 값: 재활용률(평균)"으로 설정하면 어떤 정보를 얻을 수 있나요?

    정답 확인 각 시도별로 3개 연도(2021~2023)의 **재활용률 평균**을 한눈에 비교할 수 있습니다. 예를 들어 서울의 3년 평균 재활용률은 (62.1+63.5+65.0)÷3 = 63.5% 입니다.

    응용 문제¶

    3. 아래 프롬프트를 더 좋은 프롬프트로 개선해보세요.

    원본: "이 데이터 분석해줘"

    정답 확인 (개선 예시) *"아래 시도별 1인당 폐기물 배출량 데이터에서 (1) 가장 높은 지역과 낮은 지역의 차이, (2) 연도별 변화 추세, (3) 배출량과 재활용률 사이의 관계를 각각 한 문장으로 설명해줘."* **포인트**: 구체적인 질문, 원하는 출력 형식, 데이터의 맥락을 명시하면 훨씬 정확한 답변을 얻습니다.

    🏆 도전 문제¶

    4차시에서 다운로드한 데이터 또는 다른 공공데이터(예: 시도별 인구수)를 하나 더 구해서, 오늘 사용한 배출량 데이터와 연결해보세요.

    예를 들어: "인구 대비 배출량 비율" 또는 "인구밀도와 재활용률의 관계" 등 두 데이터셋을 결합한 새로운 인사이트를 1개 이상 문장으로 작성해보세요.

    🔗 다음 장 미리보기¶

    지금까지 데이터를 찾고(4차시), 탐색하여 인사이트를 발견했습니다(5차시).

    다음 6차시에서는 발견한 인사이트를 시각적으로 표현하는 방법을 배웁니다. 같은 데이터도 막대그래프, 꺾은선그래프, 파이차트 중 어떤 것을 선택하느냐에 따라 전달력이 완전히 달라집니다. 숫자를 눈에 보이는 이야기로 바꾸는 시간, 기대해주세요! 📊
