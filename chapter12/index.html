    12장. 무대 위의 3분 — 발표와 대회 제출¶

    Part 4. 완성 — 기획서를 쓰고, 발표하고, 제출하다

    🎯 이 장에서 배우는 것¶

    • 3분 발표 스크립트를 황금 구조에 맞춰 작성하고 리허설할 수 있다
    • 대회 제출 체크리스트를 점검하고 최종 제출을 완료할 수 있다

    📚 핵심 개념¶

    개념 1: 3분 발표의 황금 구조 ⏱️¶

    비유로 시작: 3분 발표는 마치 영화 예고편과 같아요. 영화 전체를 보여주는 게 아니라, 핵심 장면만 골라서 "이 영화 꼭 봐야 해!"라는 마음이 들게 만드는 거죠. 여러분의 기획서도 마찬가지입니다. 180초 안에 심사위원이 "이 프로젝트, 정말 되겠는데?"라고 느끼게 만들어야 합니다.

    정확한 정의: 3분 발표의 황금 구조란, 제한된 시간 안에 문제 인식 → 근거 제시 → 해결책 → 시연 → 기대효과 순서로 청중을 설득하는 발표 프레임워크입니다.

    구조 한눈에 보기:

    flowchart LR A["🔥 문제 공감\n30초"] --> B["📊 데이터 근거\n40초"] B --> C["🤖 AI 솔루션\n60초"] C --> D["📱 서비스 시연\n30초"] D --> E["🌟 기대효과\n20초"]

    각 파트별 핵심 포인트:

    • 🔥 문제 공감 (30초): "여러분도 이런 경험 있지 않나요?"로 시작. 청중이 고개를 끄덕이게 만드는 질문이나 통계 하나로 시작
    • 📊 데이터 근거 (40초): 11장에서 만든 설문 결과, 공공데이터 수치를 1~2개만 제시. "10명 중 7명이 불편하다고 답했습니다"
    • 🤖 AI 솔루션 (60초): 우리 팀의 핵심 아이디어. AI가 어떤 데이터를 어떻게 처리해서 무엇을 해결하는지 명확하게
    • 📱 서비스 시연 (30초): 프로토타입 화면이나 플로우차트를 보여주며 "이렇게 작동합니다"
    • 🌟 기대효과 (20초): 숫자로 표현. "처리 시간 50% 단축", "연간 1,000명 혜택"

    개념 2: 대회 제출 체크리스트 ✅¶

    비유로 시작: 대회 제출은 마치 비행기 탑승 수속과 같아요. 여권(파일 형식), 탑승권(제출 양식), 수하물 규정(용량 제한)을 하나라도 어기면 비행기를 탈 수 없죠. 아무리 훌륭한 기획서도 제출 요건을 못 맞추면 심사 대상에서 빠집니다.

    정확한 정의: 대회 제출 체크리스트란, 최종 산출물을 기한 내에 올바른 형식으로 제출하기 위해 하나씩 확인하고 체크하는 필수 점검 목록입니다.

    제출 전 필수 점검 5가지:

    • ① 파일명 규칙: 대회 요강에 지정된 형식 준수 (예: 팀명_기획서_최종.pdf)
    • ② PDF 변환: 한글/PPT 원본이 아닌 PDF로 변환. 폰트 깨짐 확인 필수
    • ③ 개인정보 확인: 팀원 이름, 학교명, 연락처가 정확한지 재확인
    • ④ 용량 제한: 업로드 용량 초과 여부 확인 (보통 10~50MB)
    • ⑤ 마감 시간: 마감 30분 전까지 제출 완료 목표. 서버 과부하 대비

    💡 알아보기: 대부분의 대회에서 탈락 사유 1위는 "내용 부족"이 아니라 "제출 형식 오류"입니다. 파일명을 잘못 쓰거나, 마감 시간을 1분이라도 넘기면 자동 탈락되는 경우가 많아요.

    🔨 따라하기: 발표 준비부터 제출까지¶

    Step 1: 스크립트 초안 작성하기 🖊️¶

    아래 Python 코드를 실행하면, 황금 구조에 맞춘 스크립트 템플릿이 생성됩니다. 빈칸을 여러분의 프로젝트 내용으로 채워보세요.

    코드: 

    # 3분 발표 스크립트 생성기
script_template = {
    "문제 공감 (30초)": {
        "시간": "0:00 ~ 0:30",
        "핵심": "청중이 공감할 질문 또는 충격적 통계 1개",
        "예시": "여러분, 학교 앞 횡단보도에서 위험했던 적 있나요? "

        "우리팀": "___여기에 작성___"
    },
    "데이터 근거 (40초)": {
        "시간": "0:30 ~ 1:10",
        "핵심": "설문 결과 또는 공공데이터 수치 1~2개",
        "예시": "저희가 학생 80명을 대상으로 설문한 결과, "
               "72%가 '등하교 시 위험을 느낀 적 있다'고 답했습니다.",
        "우리팀": "___여기에 작성___"
    },
    "AI 솔루션 (60초)": {
        "시간": "1:10 ~ 2:10",
        "핵심": "AI가 무슨 데이터를 어떻게 처리하여 무엇을 해결하는지",
        "예시": "CCTV 영상을 AI 객체 인식으로 분석하여 "
               "과속 차량을 실시간 감지하고 경고음을 울립니다.",
        "우리팀": "___여기에 작성___"

    "서비스 시연 (30초)": {

    Step 2: 팀원 역할 분배하기 🤝¶

    # 팀원별 발표 파트 배정기
team = ["민수", "지영", "현우"]  # 팀원 이름 수정하세요

roles = {
    team[0]: ["문제 공감 (30초)", "데이터 근거 (40초)"],
    team[1]: ["AI 솔루션 (60초)"],
    team[2]: ["서비스 시연 (30초)", "기대효과 (20초)"]
}

print("🎯 팀원별 발표 파트 배정")
print("-" * 35)
for member, parts in roles.items():
    total = sum(int(p.split("(")[1].split("초")[0]) for p in parts)
    print(f"👤 {member}: {', '.join(parts)}")
    print(f"   → 담당 시간: 약 {total}초\n")

    Step 3: 리허설 타이머 돌리기 ⏰¶

    import time

def rehearsal_timer():
    sections = [
        ("문제 공감", 30), ("데이터 근거", 40),
        ("AI 솔루션", 60), ("서비스 시연", 30),
        ("기대효과", 20)
    ]

    print("🎬 리허설을 시작합니다!")
    print("각 파트가 시작되면 해당 내용을 말하세요.\n")

    total = 0
    for name, seconds in sections:
        print(f"▶ [{name}] 시작! ({seconds}초)")
        # 실제 수업에서는 time.sleep(seconds) 사용
        # time.sleep(seconds)  # 주석 해제하면 실제 타이머 작동
        total += seconds
        print(f"  ✅ 완료! (누적 {total}초)\n")

    print(f"🏁 총 발표 시간: {total}초 ({total//60}분 {total%60}초)")
    if total <= 180:
        print("👍 3분 이내! 완벽합니다!")
    else:
        print("⚠️ 3분 초과! 스크립트를 줄여주세요.")

rehearsal_timer()

    Step 4: 예상 질문 대비하기 🙋¶

    # Q&A 시뮬레이션
qa_prep = [
    {
        "질문": "이 AI 모델의 정확도는 어느 정도인가요?",
        "답변전략": "데이터 기반 답변",
        "예시답변": "유사 서비스의 논문에 따르면 약 92% 정확도이며, "
                   "저희는 학습 데이터를 지역 특화로 추가 수집해 "
                   "정확도를 높일 계획입니다."
    },
    {
        "질문": "기존 서비스와 차별점이 무엇인가요?",
        "답변전략": "비교 분석 답변",
        "예시답변": "기존 서비스 A는 알림만 제공하지만, "
                   "저희는 AI 예측을 통해 사전 예방까지 가능합니다."
    },
    {
        "질문": "실현 가능성은 어떤가요?",
        "답변전략": "단계적 계획 답변",
        "예시답변": "1단계로 프로토타입을 완성했고, "
                   "2단계에서 실제 데이터 연동 테스트를 진행할 예정입니다."
    }
]

print("🙋 예상 질문 & 답변 전략 시트")
print("=" * 45)
for i, qa in enumerate(qa_prep, 1):
    print(f"\nQ{i}. {qa['질문']}")
    print(f"   💡 전략: {qa['답변전략']}")
    print(f"   📝 예시: {qa['예시답변']}")

    💡 알아보기: 답변할 때 가장 중요한 원칙은 "모르면 모른다고 말하기"입니다. "좋은 질문입니다. 아직 검증하지 못한 부분인데, 향후 연구 과제로 삼겠습니다"라고 말하면 오히려 신뢰도가 올라갑니다.

    Step 5: 최종 제출 체크리스트 실행 📋¶

    # 대회 제출 최종 체크리스트
checklist = [
    ("파일명이 대회 규정대로 되어 있나요?", False),
    ("PDF로 변환하고 폰트 깨짐을 확인했나요?", False),
    ("팀원 이름, 학교, 연락처가 정확한가요?", False),
    ("파일 용량이 제한 이내인가요?", False),
    ("마감 30분 전까지 제출 완료 가능한가요?", False),
]

print("📋 최종 제출 체크리스트")
print("=" * 45)

all_clear = True
for i, (item, checked) in enumerate(checklist, 1):
    # 실제로는 input()으로 확인 — 여기선 시뮬레이션
    checked = True  # 모두 확인했다고 가정
    status = "✅" if checked else "❌"
    print(f"  {status} {i}. {item}")
    if not checked:
        all_clear = False

print()

    # ============================================
# 12장. 무대 위의 3분 — 발표와 대회 제출
# ============================================

# --- 1. 스크립트 구조 확인 ---
sections = [
    ("문제 공감", 30), ("데이터 근거", 40),
    ("AI 솔루션", 60), ("서비스 시연", 30),
    ("기대효과", 20)
]

print("🎤 3분 발표 황금 구조")
total = 0
for name, sec in sections:
    total += sec
    print(f"  ▶ {name}: {sec}초 (누적 {total}초)")

# --- 2. 팀원 배정 ---
team = ["민수", "지영", "현우"]
roles = {
    team[0]: ["문제 공감", "데이터 근거"],
    team[1]: ["AI 솔루션"],
    team[2]: ["서비스 시연", "기대효과"]
}
print("\n👥 팀원별 배정")
for member, parts in roles.items():
    print(f"  {member} → {', '.join(parts)}")

# --- 3. 제출 체크리스트 ---
checks = [
    "파일명 규정 준수", "PDF 변환 완료",
    "개인정보 확인", "용량 제한 확인", "마감 전 제출"
]
print("\n📋 제출 체크리스트")
for c in checks:
    print(f"  ✅ {c}")

print("\n🎉 모든 준비 완료! 제출합니다!")
