    PPT 15매, 구조가 답이다¶

    🎯 이 장에서 배우는 것¶

    • 대회 기획서의 15매 PPT 권장 구조(표지→문제→데이터→솔루션→기대효과)를 설명할 수 있다
    • 각 슬라이드의 핵심 메시지를 한 문장으로 정리하는 슬라이드 메시지 맵을 작성할 수 있다
    • 구글 슬라이드 또는 Canva에서 기획서 초안 15매의 뼈대를 완성할 수 있다

    📚 핵심 개념¶

    개념 1: 15매 PPT 구조¶

    "15매 PPT는 마치 영화 예고편과 같아요." 영화 예고편은 2분 안에 배경 설정 → 갈등 → 해결의 실마리 → 감동 포인트를 순서대로 보여줘야 관객이 "이 영화 보고 싶다!"라고 느낍니다. 기획서 PPT도 마찬가지예요. 심사위원은 15매를 넘기며 "이 팀이 어떤 문제를 발견했고, 어떻게 풀었고, 왜 가치 있는지"를 빠르게 파악하고 싶어 합니다. 순서가 뒤죽박죽이면, 아무리 좋은 아이디어도 전달되지 않아요.

    정확한 정의: 15매 PPT 구조란, 대회 기획서에서 심사위원이 기대하는 정보 흐름에 맞춰 슬라이드 순서와 매수를 미리 정해놓은 설계 도면입니다.

    권장 구조는 다음과 같습니다.

    flowchart LR A["🎬 표지\n1매"] --> B["❗ 문제 정의\n2매"] B --> C["📊 데이터 분석\n3매"] C --> D["🤖 AI 솔루션\n3매"] D --> E["📱 서비스 시나리오\n2매"] E --> F["🌟 기대효과\n2매"] F --> G["👥 팀 소개\n1매"] G --> H["📖 참고문헌\n1매"]

    각 파트의 역할을 좀 더 자세히 볼까요?

    • 표지 (1매): 프로젝트 이름, 팀명, 대회명, 날짜. 첫인상을 결정합니다.
    • 문제 정의 (2매): "세상에 이런 문제가 있다" → "이 문제가 왜 심각한지 데이터로 증명". 심사위원이 공감해야 다음 장을 넘깁니다.
    • 데이터 분석 (3매): 어떤 데이터를 수집했고, 어떤 패턴을 발견했는지. 차트와 그래프가 핵심입니다.
    • AI 솔루션 (3매): 어떤 AI 모델/기술을 사용했고, 왜 이 방법을 선택했으며, 성능은 어떤지.
    • 서비스 시나리오 (2매): 실제 사용자가 이 솔루션을 어떻게 쓰는지 보여주는 화면 흐름.
    • 기대효과 (2매): 사회적·경제적 가치, 확장 가능성.
    • 팀 소개 (1매): 팀원 역할과 강점.
    • 참고문헌 (1매): 인용한 논문, 데이터 출처, 뉴스 등.

    💡 알아보기: 왜 하필 15매일까? 대부분의 학생 대회(공모전)에서 10~20매를 요구합니다. 15매는 너무 적지도, 너무 많지도 않은 분량으로, 발표 시간 7~10분에 딱 맞습니다. 슬라이드 한 장당 약 40초가 기본 원칙이에요.

    개념 2: 슬라이드 메시지 맵¶

    "메시지 맵은 마치 건물의 철골 구조와 같아요." 건물을 지을 때 벽지나 인테리어보다 철골을 먼저 세우듯, PPT를 만들 때도 디자인보다 각 슬라이드가 전달할 핵심 메시지 한 문장을 먼저 정해야 합니다.

    정확한 정의: 슬라이드 메시지 맵이란, 15매 각각에 "이 슬라이드를 본 심사위원이 기억해야 할 한 문장"을 미리 적어둔 계획표입니다.

    예시 — '청소년 수면 부족 해결 AI 챗봇' 프로젝트의 메시지 맵:

    • 1매(표지): "SleepBuddy — AI가 만드는 청소년 맞춤 수면 습관"
    • 2매(문제①): "한국 청소년 68%가 권장 수면 시간에 미달한다"
    • 3매(문제②): "수면 부족은 학업·정신건강·성장 모두에 악영향을 준다"
    • 4매(데이터①): "2,000명 설문조사 결과 — 취침 시간, 스마트폰 사용, 스트레스 상관관계"
    • 5매(데이터②): "공공데이터 분석 — 지역별·학년별 수면 패턴 차이"
    • 6매(데이터③): "핵심 발견 — 스마트폰 사용 시간이 30분 늘면 수면 시간 22분 감소"
    • 7매(솔루션①): "자연어 처리 기반 AI 챗봇이 매일 밤 수면 루틴을 코칭한다"
    • 8매(솔루션②): "GPT API + 감정 분류 모델 결합 구조"
    • 9매(솔루션③): "2주 테스트 결과 — 평균 수면 시간 37분 증가"
    • 10매(시나리오①): "사용자가 챗봇과 대화하는 화면 흐름 (카카오톡 연동)"
    • 11매(시나리오②): "주간 수면 리포트 화면 — 개선 추이를 한눈에"
    • 12매(기대효과①): "청소년 건강 개선 + 학교 보건실 연계 가능성"
    • 13매(기대효과②): "전국 중·고교 확대 시 100만 명 혜택 예상"
    • 14매(팀 소개): "데이터 분석·AI 개발·디자인 — 3명이 만든 시너지"
    • 15매(참고문헌): "논문 3편, 공공데이터 2건, 뉴스 기사 4건"

    🤔 생각해보기: 위 메시지 맵에서 2매→3매로 넘어갈 때 자연스럽나요? "얼마나 심각한지(숫자)" → "왜 심각한지(영향)"으로 이어지기 때문에 설득력이 커집니다. 여러분의 프로젝트도 이렇게 숫자 → 의미 흐름을 만들어 보세요.

    🔨 따라하기¶

    Step 1: 메시지 맵 작성하기 (종이 or 메모장)¶

    연습장이나 메모 앱을 열고, 아래 Python 코드처럼 15매의 제목과 핵심 메시지를 한 줄씩 작성하세요. 코드로 정리하면 나중에 팀원과 공유하기도 편합니다.

    코드: 

    # 메시지 맵 생성기 — 우리 팀 프로젝트에 맞게 수정하세요!
message_map = {
    1:  {"파트": "표지",       "메시지": "프로젝트 이름과 한 줄 소개를 적으세요"},
    2:  {"파트": "문제 정의①", "메시지": "우리가 발견한 문제를 숫자로 보여주세요"},
    3:  {"파트": "문제 정의②", "메시지": "그 문제가 왜 중요한지 설명하세요"},
    4:  {"파트": "데이터①",   "메시지": "어떤 데이터를 모았는지 적으세요"},
    5:  {"파트": "데이터②",   "메시지": "데이터에서 발견한 패턴을 적으세요"},
    6:  {"파트": "데이터③",   "메시지": "가장 중요한 인사이트 한 가지를 적으세요"},
    7:  {"파트": "AI 솔루션①", "메시지": "어떤 AI 기술로 해결하는지 적으세요"},
    8:  {"파트": "AI 솔루션②", "메시지": "시스템 구조를 간단히 적으세요"},
    9:  {"파트": "AI 솔루션③", "메시지": "테스트 결과나 예상 성능을 적으세요"},
    10: {"파트": "시나리오①",  "메시지": "사용자가 처음 접하는 화면을 적으세요"},
    11: {"파트": "시나리오②",  "메시지": "핵심 기능 사용 흐름을 적으세요"},
    12: {"파트": "기대효과①",  "메시지": "사회적 가치를 적으세요"},
    13: {"파트": "기대효과②",  "메시지": "확장 가능성을 적으세요"},
    14: {"파트": "팀 소개",    "메시지": "팀원 역할과 강점을 적으세요"},
    15: {"파트": "참고문헌",   "메시지": "인용 출처를 모두 적으세요"},
}

print("=" * 50)
print("📋 우리 팀 슬라이드 메시지 맵")
print("=" * 50)
for slide_num, info in message_map.items():
    print(f"  슬라이드 {slide_num:2d}매 [{info['파트']}]")
    print(f"    → {info['메시지']}")
    print()

    Step 2: 구글 슬라이드 / Canva에서 뼈대 만들기¶

    1. 구글 슬라이드: slides.google.com 접속 → 새 프레젠테이션 → 빈 슬라이드 15매 추가
    2. Canva: canva.com 접속 → 프레젠테이션(16:9) → 15페이지 생성

    각 슬라이드에 제목(파트명)과 핵심 메시지 한 문장만 먼저 입력합니다. 디자인은 아직 하지 마세요!

    Step 3: 슬라이드별 요소 배치 계획¶

    메시지를 넣었다면, 각 슬라이드에 어떤 시각 요소가 필요한지 메모합니다.

    # 슬라이드별 필요 요소 체크리스트
visual_elements = {
    "문제 정의①": ["통계 수치 강조 (큰 숫자)", "출처 표기"],
    "문제 정의②": ["뉴스 기사 캡처 or 인포그래픽"],
    "데이터①":   ["데이터 수집 과정 다이어그램"],
    "데이터②":   ["막대 차트 or 히트맵"],
    "데이터③":   ["핵심 수치 한 개를 크게 강조"],
    "AI 솔루션①": ["기술 키워드 아이콘"],
    "AI 솔루션②": ["시스템 구조도 (플로우차트)"],
    "AI 솔루션③": ["성능 비교 차트"],
    "시나리오①":  ["앱 화면 목업(mockup)"],
    "시나리오②":  ["사용 흐름 화살표 다이어그램"],
    "기대효과①":  ["수혜자 수 등 임팩트 숫자"],
    "기대효과②":  ["확장 로드맵 타임라인"],
}

for slide, elements in visual_elements.items():
    print(f"📌 {slide}")
    for e in elements:
        print(f"   □ {e}")

    실행 결과: 

    📌 문제 정의①

   □ 출처 표기

   □ 뉴스 기사 캡처 or 인포그래픽
📌 데이터①
   □ 데이터 수집 과정 다이어그램
... (이하 동일 형식)

    Step 4: 흐름 점검 — "그래서?" 테스트¶

    완성된 메시지 맵을 1매부터 15매까지 순서대로 읽으며, 매 슬라이드 뒤에 "그래서?"라고 물어보세요. 다음 슬라이드가 자연스러운 답이 되면 흐름이 좋은 겁니다.

    flowchart TD A["2매: 청소년 68%가 수면 부족"] -->|"그래서 뭐가 문제인데?"| B["3매: 학업·건강에 악영향"] B -->|"그래서 증거가 있어?"| C["4매: 2,000명 설문 데이터 수집"] C -->|"그래서 뭘 발견했어?"| D["5매: 스마트폰-수면 상관관계"] D -->|"그래서 어떻게 해결해?"| E["7매: AI 챗봇으로 수면 코칭"] E -->|"그래서 효과가 있어?"| F["9매: 수면 시간 37분 증가"]

    흐름이 끊기는 곳이 있다면, 슬라이드 순서를 바꾸거나 메시지를 수정하세요.

    Step 5: 초안 완성 체크¶

    아래 코드를 실행해 우리 팀의 준비 상태를 점검합니다.

    # 초안 완성도 체크리스트
checklist = [
    ("15매 모두 생성했는가?", True),     # 본인 상태에 맞게 수정
    ("각 슬라이드에 핵심 메시지가 있는가?", True),
    ("'그래서?' 테스트를 통과했는가?", True),

]

done = sum(1 for _, status in checklist if status)

    ✅ 점검하기¶

    기본 문제: 15매 구조에서 "데이터 분석" 파트는 몇 매이며, 어떤 역할을 하나요?

    정답 확인 3매입니다. ①어떤 데이터를 수집했는지, ②데이터에서 발견한 패턴, ③가장 중요한 인사이트 한 가지를 각각 보여주는 역할을 합니다.

    응용 문제: "그래서?" 테스트란 무엇이며, 왜 중요한가요?

    정답 확인 각 슬라이드의 메시지를 읽은 뒤 "그래서?"라고 물었을 때, 다음 슬라이드가 자연스러운 답이 되는지 확인하는 방법입니다. 이 테스트를 통해 슬라이드 간 논리적 흐름이 끊기는 곳을 찾아 수정할 수 있기 때문에 중요합니다.

    🚀 도전 문제: 심사위원의 관점에서 여러분 팀 기획서 초안의 강점 3가지와 약점 3가지를 작성해 보세요. (힌트: "문제가 공감되는가?", "데이터가 충분한가?", "솔루션이 실현 가능한가?" 등의 기준으로 평가)

    📌 정리하기 - 15매 PPT의 핵심은 구조다. 표지→문제→데이터→솔루션→시나리오→기대효과→팀→참고문헌 순서를 지키자. - 메시지 맵을 먼저 만들고, 디자인은 나중에 한다. 각 슬라이드에는 핵심 메시지 딱 한 문장. - "그래서?" 테스트로 슬라이드 간 흐름을 점검하면 논리적 빈틈을 잡을 수 있다.
